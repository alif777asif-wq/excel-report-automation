## Project description (545 characters)

```
Developed a Python automation that turns messy monthly sales exports into a clean, formula-driven Excel report. Built and tested on synthetic data, so no real client files were used.

Core Features
- Cleans CSV and XLSX exports with mixed formats
- Fixes dates, regions, duplicates and text numbers
- Live summaries, charts and KPIs from formulas
- Cleaning log for every file
- Re-runs when next month's export arrives
- Formulas checked by independent recalculation

Measured run: 12 exports, 11,442 orders, 149 formulas checked, 0 mismatches.
```
