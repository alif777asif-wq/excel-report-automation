# Excel report automation: messy exports to a verified report (demo project)

A Python pipeline that takes messy monthly sales exports (CSV and XLSX from different branches), cleans
and consolidates them, and writes an Excel report whose every figure is a live formula. The report is then
**recalculated independently in LibreOffice** and compared with the values stored in the file.

Everything here runs on **synthetic data** (fictional reps and products, generated by `make_raw.py`). It is a
personal demo project, not client work.

## What it does
| Step | Module |
|---|---|
| Read CSV and XLSX exports exactly as delivered | `clean.py` |
| Map 3 header spellings to one schema, parse 4 date styles, standardize regions, convert text numbers, trim padded cells | `clean.py` |
| Remove blank rows, footer rows and duplicates; reject rows with no order ID; recompute missing amounts | `clean.py` |
| Count every fix per file (the cleaning log) | `clean.py`, `Cleaning Log` sheet |
| Write the workbook: Summary, By Region, Monthly, Clean Data (an Excel table), Cleaning Log | `build_report.py` |
| Recalculate in LibreOffice, compare, prove the check can fail | `verify.py` |
| End-to-end run, plus a refresh when next month's export arrives | `run_demo.py` |

## How to read these numbers
- The exports are generated with **known problems**, so cleaning accuracy is measured against ground truth.
- Real exports have problems this generator does not. A new source usually needs a short pass to teach the
  cleaner its header spellings and formats.
- The workbook uses SUMIFS summary tables and charts. It has no pivot tables and no VBA macros.
- Timings come from one machine.

## Run it
Arch Linux:
```
sudo pacman -S --needed libreoffice-fresh
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run_demo.py                         # about 30 seconds
python -m unittest discover -s tests -v    # 14 tests
```
Open `output/Sales_Report.xlsx` in Excel or LibreOffice.

## The portfolio images
`boards/` holds the six Upwork portfolio images as self-contained HTML and CSS. `build_boards.py` generates them
from `sample_output/run_report.json` and the real source files, so no figure is typed by hand.
`export.py` renders them at 3840 x 2160 (needs `playwright` and Chromium). See `DELIVERY-NOTES.md`.
